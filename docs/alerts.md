# 防疫公告（衛生局警戒範圍、曾至地點、採檢站）

地方衛生局常以海報或新聞稿公布「警戒範圍村里」、「曾至地點」與「採檢站」，通常比疾管署的聚集資料更早。
這些公告沒有 API，所以由維護者輸入、經審核後顯示在登革熱地圖上。

## 在地圖上看到什麼

- **動態地圖**：上方出現「防疫公告」提示；點開看全文。
- **聚集警示**：面板最上方列出生效中的公告。
- **地圖圖層**：警戒範圍村里（橘色虛線框）、曾至地點（三角形）、採檢站（紅色水滴；過期變淡）。
  點地圖上的符號可看說明與「導航」。
- **公告全文**：警戒範圍、曾至地點與期間、採檢站（今天／即將／已結束、導航、加入行事曆）、症狀提醒、原始公告連結。
- **我在警戒範圍內嗎？**：用手機定位比對，**只在使用者裝置上計算，不傳送、不儲存位置**。
- 過了「有效期限」自動不再顯示；超過有效期限 7 天的公告在下次部署時從網站資料中移除。

## 怎麼新增一則公告（GitHub 表單）

1. 到 repo 的 **Issues → New issue → 新增防疫公告**。
2. 依衛生局原始公告填寫（範例見下）。海報上的文字請轉成文字輸入，不要上傳圖片。
3. 送出後，系統（`.github/workflows/alert-from-issue.yml`）會自動：
   - 確認送出者是本專案維護者（其他人的 issue 不處理）；
   - 檢查內容：村里是否存在且屬於該縣市、日期與時段格式、座標是否在警戒範圍附近、來源網址是否為允許的網域；
   - 有問題時在 issue 留言列出，**編輯 issue 修正後會自動重新檢查**；
   - 沒問題時建立分支 `alert/issue-<編號>` 與合併請求（PR）。
4. **審核者**對照原始公告核對後合併 PR；合併後約 3 分鐘上線，issue 自動關閉。

> 若系統留言「無法自動建立合併請求」，請到 **Settings → Actions → General** 勾選
> 「Allow GitHub Actions to create and approve pull requests」，或直接點留言中的連結手動建立。

### 欄位填寫範例（2026-11-02 高雄市小港區）

| 欄位 | 填寫 |
|---|---|
| 縣市 | 高雄市 |
| 鄉鎮市區 | 小港區 |
| 公告標題 | 高雄市小港區本土登革熱群聚 |
| 發布日期／有效期限 | 2026-11-02／2026-11-16（有效期限依衛生局指示；未說明時建議發布後 14 天） |
| 發布單位 | 高雄市政府衛生局 |
| 來源網址 | 衛生局網站或官方臉書貼文網址（也接受主要新聞網站） |
| 警戒範圍村里 | 港南里、小港里、港墘里、港后里、港明里、港興里、港口里、港正里 |
| 曾至地點 | `99五金賣場｜高雄市小港區小港路186號｜10/17｜11/2｜曾至港南里活動或在賣場採購的民眾，請至採血站檢驗。｜` |
| 採檢站 | `小港衛生所｜高雄市小港區小港二街10號｜11/3, 11/4｜08:30-11:30, 14:00-16:30｜` |

- 日期可寫 `11/3`（年份取發布日期）或 `2026-11-03`；時段寫 `08:30-11:30`，多段以逗號分隔。
- **座標**選填：在 Google 地圖對地點按右鍵，複製「緯度, 經度」貼上。沒填座標時地圖上不畫符號，但公告全文仍列出，導航改用地址。
- 同一鄉鎮同一天有第二則公告時，檔名會自動加上 issue 編號。要修改已上線的公告，請直接改 `content/alerts/<id>.json` 開 PR。

## 檔案與格式

- 原始資料：`content/alerts/<id>.json`（一則一檔，維護者編輯）。格式：

  ```jsonc
  {
    "id": "2026-11-02-kaohsiung-xiaogang",          // 須與檔名相同
    "title": "高雄市小港區本土登革熱群聚", "titleEn": "…（選填）",
    "county": "64000", "town": "64000110",          // 內政部縣市、鄉鎮代碼
    "issuedAt": "2026-11-02", "validUntil": "2026-11-16",   // 最長 60 天
    "issuer": "高雄市政府衛生局", "sourceUrl": "https://…",
    "villages": ["64000110007", …],                 // 內政部 11 碼村里代碼
    "exposureSites": [{ "name", "address", "from", "to", "note"?, "lng"?, "lat"? }],
    "screeningStations": [{ "name", "address", "dates": ["2026-11-03"], "hours": ["08:30-11:30"], "lng"?, "lat"? }],
    "note": "…（選填）", "noteEn": "…（選填）"
  }
  ```

- 網站資料：`public/data/alerts.json` 由 `scripts/alerts/build.mjs` 在每次建置時產生（`npm run build` 的 prebuild），
  依代碼補上村里中英文名稱與村里界線（`taiwan-atlas` 的內政部村里界線）。**任何一個檔案驗證失敗，建置就失敗**，不會發布半套資料。
  本機只檢查：`npm run alerts:check`。
- 驗證規則（`scripts/alerts/lib.mjs`）：只允許列出的欄位；文字不可含 `<`、`>` 或控制字元；
  來源網址限 https 的 `*.gov.tw`、官方臉書與少數主要新聞網站；座標須在警戒範圍附近（可抓出經緯度填反）。

## 安全

- 表單內容視為不可信輸入：只經由環境變數交給轉換程式，不會被當成指令執行；只處理維護者送出的 issue。
- 頁面上所有公告文字只以純文字顯示；連結只允許上述網域。
- 定位只在瀏覽器中比對，不送到任何伺服器。
